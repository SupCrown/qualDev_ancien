# TP3 Geometry - Bibliothèque Rust pour la manipulation de vecteurs 2D

## 📌 Description
Cette bibliothèque fournit des outils pour manipuler des vecteurs 2D en Rust.  
Elle permet d’effectuer des opérations telles que la normalisation, le produit scalaire, la rotation et la colinéarité.

## 📚 Documentation
La documentation est accessible en ouvrant doc/tp3_geometry/index.html avec votre navigateur.
elle est accessible aussi en executant cargo doc --open en étant dans le dossier /tp3_geometry.
